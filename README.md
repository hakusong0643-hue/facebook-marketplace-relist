# Marketplace 重新刊登與社團上架

這個 ChatGPT Skill 可批次重新刊登 Facebook Marketplace 上符合資格的車輛，並透過「在更多地方上架」補發到尚未刊登的中古車買賣社團。兩項操作也可以分開執行。

## 安裝與使用

可將下列指令交給支援安裝 Skills 的 ChatGPT 或 Codex：

> 幫我安裝 https://github.com/hakusong0643-hue/facebook-marketplace-relist.git

執行時請使用已登入 Facebook、可操作 Marketplace 賣家介面的瀏覽器。

> 用 $facebook-marketplace-relist 幫我重新刊登所有可重新刊登的車，再補上還沒上架的社團。

可在指令中指定車款、社團或補發數量。操作流程見 [SKILL.md](SKILL.md)。
